* Lessons
- A redaction task's own verification artifact can re-introduce scrubbed terms
  if its directory name or grep pattern quotes them verbatim; keep both generic.
- Container hostnames and platform internals also surface in historical
  verification tables under =.artifacts/= and =SESSION_LOG.md=, not only in
  top-level docs.
- Node's ~URL~ parser canonicalizes IPv4-mapped IPv6 literals like
  =[::ffff:127.0.0.1]= into hex groups (=[::ffff:7f00:1]=), so IPv6
  classification must expand all eight 16-bit groups rather than matching
  dotted-quad strings.
- Checking the per-user rate window before the global concurrency cap avoids
  burning a user's quota when a global burst rejects their request, while still
  enforcing the global cap on exempt admin calls.
- Dropping unused direct dependencies alongside a clean install and non-breaking
  =npm audit fix= cleared all 14 production advisories without manual overrides.
- Unit-testing a security guard module in isolation does not catch entrypoint
  control-flow ordering bugs; pair security guards with an entrypoint ordering
  invariant test whenever the entrypoint cannot be imported directly.
- Inspecting the live Hermes extraction backend on the VPS prevented building
  unnecessary local proxy machinery: Hermes =v0.23.3= already gates
  ~web_extract_tool~ with ~async_is_safe_url~ and the active extraction backend
  fetches remotely outside the VPS container.

* Follow-ups
- If the VPS Hermes profile is ever switched from its remote extraction backend
  to a local-fetch backend, verify that backend uses Hermes's
  ~create_ssrf_safe_client()~ before enabling it in production.
- Consider enabling GitHub Dependabot security updates on the public repository.
- Migrate or retire any remaining legacy items in the private =issues.org= file
  when convenient.
